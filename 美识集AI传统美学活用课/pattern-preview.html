当前底纹：宣纸纹理

模拟宣纸的温润质感，极浅的纸张纤维噪点叠加柔和的色块晕染，是最百搭的基础底纹。几乎不增加视觉负担，长时间阅读也不疲劳。

温润雅致 零视觉负担 适合长文阅读 全站通用

效果预览

这是一段示例文字，用来展示底纹与正文的搭配效果。传统美学的核心不在于繁复的装饰，而在于恰到好处的留白与质感。

好的底纹应该是"隐形"的——用户不会特意注意到它的存在，但会莫名觉得这个页面"看起来很舒服"。底纹的作用是营造氛围，而不是抢夺内容的注意力。

所有底纹均采用纯CSS + SVG实现，零版权风险，加载速度极快，可以直接复制到你的项目中使用。

使用方法

1. 点击上方按钮切换不同底纹风格

2. 调整透明度滑块，找到最适合的浓度

3. 复制下方CSS代码，粘贴到你的页面样式中

4. 建议底纹透明度控制在30%-80%之间，根据内容卡片的背景透明度灵活调整

/* 宣纸纹理底纹 */ body { background-color: #EEE8DA; background-image: radial-gradient(ellipse at 20% 30%, rgba(137,109,89,0.04) 0%, transparent 50%), radial-gradient(ellipse at 80% 70%, rgba(65,76,57,0.03) 0%, transparent 50%), url("data:image/svg+xml,..."); }

八种底纹适用场景建议

宣纸纹理：全站通用，尤其适合长文阅读、课程内容页

回纹暗纹：适合首页、导航栏、标题区，增加秩序感和文化氛围

云纹暗纹：适合国风插画、场景概念设计相关页面

水彩晕染：适合首屏Hero区、课程介绍页，增加艺术感

远山意境：适合页脚、章节分隔区，营造东方空间感

几何格纹：适合工具页、数据展示区，增加理性秩序感

冰裂纹：适合陶瓷、器物相关内容页，呼应主题

卷草暗纹：适合服饰、织物、装饰艺术相关内容页
