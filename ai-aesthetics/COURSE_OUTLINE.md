# 《美识集·AI创作者传统美学活用课》课程要点与提纲

## 一、课程定位

**一句话定位**

把中外传统美学整理成 AI 创作者可以直接调用的色彩、纹样、建筑、绘画、材质与提示词语言。

**目标学习者**

- AI 绘画创作者
- 平面设计师与文创从业者
- 设计类学生
- 需要快速理解传统美学并转化为创作描述的内容从业者

**学习后应能做到**

1. 识别传统色彩的主色、辅助色、点缀色关系，并写出可复用的配色提示词。
2. 辨认高频传统纹样的名称、结构、寓意与适用边界，减少 AI 造型失真。
3. 用建筑、绘画、器物三类载体描述风格，而不是只写一个空泛的风格名。
4. 根据海报、插画、场景、文创产品等任务组合知识，形成完整创作方案。
5. 对生成结果进行传统美学层面的检查、修正和二次优化。

## 二、课程设计原则

- **AI 原生**：只保留能转化成提示词、参数、检查项或创作决策的内容。
- **三层递进**：底层视觉基底 -> 实体艺术载体 -> 创作实战专题。
- **学练一体**：每个知识模块对应一个可操作工具或创作练习。
- **可核验**：知识点标注时期、地区、资料类型，并区分史实、传说与审美赏析。
- **不替代创作**：工具负责降低检索和描述成本，最终判断仍由创作者完成。

## 三、课程总地图

### 第一层：底层视觉基底

#### 模块 1：传统色彩体系

**核心问题**

为什么同样是红、青、棕，不同文明与时期的画面气质完全不同？

**学习要点**

- 中国体系：青瓷、敦煌、宫廷、建筑彩画、文房器物等色彩逻辑。
- 西方体系：文艺复兴、巴洛克、拜占庭、莫兰迪、地中海与北非色系。
- 主色、辅助色、点缀色的比例与画面职责。
- 饱和度、明度、冷暖、色温与“年代感”的关系。
- 常见问题：过度饱和、比例失衡、色相过多、材质色与装饰色混淆。

**工具**

- 传统配色生成器：主题切换、五色色板、色值复制、提示词生成、随机推荐。

**完成标准**

选择任意主题，输出一条包含色彩比例、质感、光线与氛围的 AI 配色提示词。

#### 模块 2：传统纹样与图案

**核心问题**

怎样描述纹样，才能让 AI 画得像，而不是只画出一个“差不多”的花纹？

**学习要点**

- 几何纹样：回纹、云雷纹、万字纹、冰裂纹、卷草纹。
- 自然纹样：云纹、水纹、缠枝花卉纹、松竹梅纹。
- 瑞兽与吉祥纹样：龙纹、凤纹、祥云纹、蝙蝠纹、如意纹。
- 主体纹样、辅助纹样、底纹的层级关系。
- 造型、线条、疏密、重复方式、材质与留白描述。
- 使用边界：尊重历史与民俗语境，避免乱用和不必要的神秘化。

**工具**

- 纹样拆解卡片：分类筛选、抽象结构图、寓意、场景、提示词模板、收藏。

**完成标准**

选择一种纹样，分别写出主体纹样和底纹版本，并说明排列方式。

### 第二层：实体艺术载体

#### 模块 3：经典建筑风格

**核心问题**

怎样用结构构件和空间关系表达建筑风格，而不是只写“古风建筑”？

**学习要点**

- 中国建筑：徽派民居、唐宋宫殿、江南园林、敦煌石窟。
- 西方建筑：古希腊罗马、哥特式、巴洛克、拜占庭。
- 观察顺序：整体轮廓 -> 结构构件 -> 材料 -> 色彩 -> 环境。
- 关键词：屋顶、墙体、门窗、柱式、拱券、穹顶、院落、轴线。
- 常见问题：结构混搭、尺度失真、飞檐角度错误、装饰过度。

**工具**

- 建筑关键词卡片：按观察顺序生成结构化提示词。

**完成标准**

以一张参考照片为对象，输出建筑结构、材料、光线和氛围的分层描述。

#### 模块 4：古典绘画风格

**核心问题**

怎样迁移一幅画的审美逻辑，而不是复制某件具体作品？

**学习要点**

- 中国绘画：文人山水、工笔花鸟、敦煌壁画、界画。
- 西方绘画：文艺复兴油画、巴洛克光影、印象派色彩。
- 构图、空间、透视、用笔、笔触、设色、光源与叙事焦点。
- 风格迁移提示词公式：主体 + 构图 + 媒介 + 笔触 + 光色 + 时代特征。
- 版权边界：描述公开风格特征，不复刻受保护作品。

**工具**

- 风格迁移句式生成器。

**完成标准**

选择一种绘画逻辑，将普通主题迁移成新的原创画面，不直接复现名作构图。

#### 模块 5：传统器物质感

**核心问题**

怎样解决 AI 常见的“塑料感”和“材质假”？

**学习要点**

- 陶瓷：釉面、开片、透光、积釉、边缘高光。
- 漆器：髹涂质感、光泽、嵌饰与层叠边缘。
- 玉器：温润透光、内部絮状结构、柔和反射。
- 青铜器：氧化层、铸造细节、凹凸与暗部层次。
- 织锦：经纬、图案、褶皱、垂坠与反光。
- 材质提示词顺序：材质 -> 表面 -> 光线 -> 磨损 -> 镜头。

**工具**

- 材质提示词库与对比示例。

**完成标准**

为同一种器物分别生成陶瓷、玉器和青铜质感描述，并说明光线差异。

### 第三层：创作实战专题

#### 模块 6：国风插画全流程

- 选题与参考边界。
- 配色 -> 纹样 -> 构图 -> 主体 -> 材质 -> 氛围。
- 分阶段生成与局部修正。
- 输出完整提示词和负面提示词。

#### 模块 7：传统风海报与文创设计

- 节日海报的信息层级与视觉中心。
- 文创包装上的元素提取、简化与再设计。
- 传统元素与现代版式、字体、产品结构的结合。
- 避免元素堆砌和文化符号误用。

#### 模块 8：古风与古典场景概念设计

- 中国场景：院落、轴线、山水关系、气候与生活方式。
- 西方场景：公共空间、宗教空间、柱廊、穹顶与光影。
- 场景中的建筑、人物、器物和纹样一致性检查。

#### 模块 9：风格稳定控制与二次优化

- 固定视觉变量：色相区间、光线方向、媒介、线条、镜头和构图。
- 建立个人风格词表与负面词表。
- 跨朝代、跨文明元素的融合原则。
- 对局部结构、材质、纹样和文字区域的定向修正。

#### 模块 10：结课项目

从“配色、纹样、建筑、绘画、材质”中任选三项，完成一套原创视觉方案。

**交付物**

- 1 张主视觉或场景图
- 1 张配色与纹样说明卡
- 1 份可复现提示词
- 1 份传统美学自检清单

## 四、HTML 站点信息架构

1. **课程首页**：课程定位、三层路径、工具入口与学习进度。
2. **十节互动课**：每课包含讲解、互动演示、三题检测、操作练习、深度思考和公开资料延伸。
3. **传统配色生成器**：主题切换、五色板、HEX/RGB/CMYK、复制、提示词和随机推荐。
4. **传统纹样拆解卡**：分类筛选、结构示意、寓意、场景、提示词、收藏。
5. **中外风格对比器**：山水、建筑、色彩等主题的东西方并排比较。
6. **文化扩展库**：雕塑、书法篆刻、古典园林、传统服饰、节日节气、中外非遗审美案例。

## 五、内容与资料规范

- 只使用公开可查的博物馆、权威艺术史、官方文旅和非遗资料。
- 传统色值统一标注为“屏幕参考值”，不宣称为文物测色结果。
- 历史、传说、审美赏析分开标注。
- 不生成受版权保护作品的完整复刻图。
- 不把特定民族、地区或文明置于优劣框架中。
- 不确定的色名、典故、构件名称不收录。

## 六、验收标准

- 课程首页与全部课时 HTML 可在本地直接打开。
- 桌面端和移动端无横向溢出、遮挡或按钮文字溢出。
- 每课至少有一个可操作交互、三题检测和一项思考练习。
- 三大工具均可交互，关键操作有明确反馈。
- 课程内容覆盖底层、载体、实战三层，知识点能落到创作动作。
- 页面沿用暖象牙、深橄榄、黏土棕、鼠尾草绿、尘粉体系。
- 页面不依赖版权不明的完整艺术品图片。
